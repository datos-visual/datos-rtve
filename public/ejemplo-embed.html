Código para incrustar

Para incluir este mapa en tu sitio web, copia y pega este código HTML:

<iframe src="URL_DE_TU_SITIO/embed/mapa" width="100%" height="600" style="border:0; max-width:100%;" title="Mapa de Fosas RTVE" allow="geolocation" loading="lazy"> </iframe>

Recomendaciones

  • El mapa se adaptará automáticamente al ancho del contenedor donde lo coloques.
  • La altura mínima recomendada es de 500px para una buena experiencia de usuario.
  • Puedes ajustar los valores de width y height según tus necesidades.
  • Para un mejor rendimiento, el iframe utiliza loading="lazy".
